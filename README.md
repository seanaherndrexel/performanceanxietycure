# performanceanxietycure.com

Static site for The Performance Anxiety Cure by Sean Stephens. Hosted on Render (static site).

- Build: `python3 build.py` → `public/`
- Add an article: drop a file in `posts/` (see ARTICLE_GUIDE.md), tick the keyword in keywords.md, commit to `main`. Render redeploys automatically.
- Amazon link: change `BUY_URL` at the top of build.py once the book's direct Amazon link is live.
- KDP print and ebook cover files live in `kdp/` (not published to the site).
