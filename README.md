# performanceanxietycure.com

Jekyll site for The Performance Anxiety Cure by Sean Stephens, hosted free on GitHub Pages (builds automatically on every commit to `main`).

- Add an article: drop a file in `_posts/` following ARTICLE_GUIDE.md, tick the keyword in keywords.md, commit to `main`.
- Method pages live in `_method/`. Layouts and the buy box live in `_layouts/` and `_includes/`.
- Amazon link: change `buy_url` in `_config.yml` once the book's direct Amazon link is live.
- KDP print and ebook cover files live in `kdp/` (excluded from the site).
